## 🚀 Project Vision
Modern career growth mein sirf skills kafi nahi, balki sahi direction aur resilience (himmat) zaroori hai. **AuraPath AI** ko **Muhammad Bilal** ne isliye design kiya taake career roadmap ko "Data-Driven" banaya ja sakay. Ye system aapki profile analyze karta hai aur aapko market ki sahi industry se match karta hai, jabki **Zen Mode** aapki mental strength ko barqarar rakhta hai.

---

## 🏗️ Technical Architecture

### 1. Nexus & Pathfinder (Analytical Engine)
* **Deep CV Audit:** User ki strengths, weaknesses aur skill matrix ka detailed analysis.
* **Skill-Based Matching:** User ki profile ko analyze kar ke wahi companies aur industries suggest karta hai jahan hiring ka chance 100% hai.

### 2. Zen Mode (Psychological Layer)
* **Zero-Question Protocol:** Bina kisi sawal ke, user ki profile ke mutabiq direct high-energy motivation.
* **Legendary Failure Analysis:** Thomas Edison, Colonel Sanders, aur J.K. Rowling ki life-struggles se user ko "Warrior Mindset" dena.

### 3. Voice Intelligence
* **Whisper-V3 Integration:** User voice commands ke zariye interact kar sakta hai, aur system usi language (Urdu/English/Roman) mein respond karta hai.
